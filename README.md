
# ☕ Cafe Website Template

A modern, responsive cafe website template built with HTML and CSS. Designed for cafes, coffee shops, and small businesses looking for a clean online presence.

## 🌐 Live Preview
[View Website](https://matsugi-dev.github.io/Cafe-template/)

## ✨ Features
- Responsive layout for mobile and desktop
- Hero section with call-to-action buttons
- Menu sections for coffee, bakery, and other drinks
- About section
- Business hours and contact information
- Customizable colors, text, and branding
- Clean HTML and CSS

## 🛠️ Built With
- HTML
- CSS

## 📸 Preview
Visit the live demo to see the website.

## 🚀 Getting Started

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Edit the text, colors, menu, and business information.
4. Customize it for your own cafe.

## 🎨 Customization

You can customize the template by editing `index.html`.

- **Colors:** Change the CSS variables inside `:root`
- **Cafe name:** Edit the logo text and page title
- **Menu:** Update menu items and prices
- **About:** Replace the sample cafe story
- **Contact:** Change the address, hours, and contact information
